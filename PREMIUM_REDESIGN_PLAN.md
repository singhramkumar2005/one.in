## Design Principles
✨ **Playful but Professional**
🎨 **Soft Colors with High Contrast Text**
🔲 **Rounded Cards with Bold Borders**
📱 **Mobile-First Responsive**
🎯 **Clear Visual Hierarchy**
💫 **Subtle Animations**
🎪 **Decorative Elements (blobs, patterns)**

## Color Usage Guide
- **Primary Coral (#FF8B7B)**: CTA buttons, important actions
- **Secondary Mint (#7DD3C0)**: Success states, positive actions
- **Yellow (#FFD93D)**: Highlights, warnings, achievements
- **Peach (#FFD6BA)**: Soft backgrounds, cards
- **Lavender (#C7CEEA)**: Info sections, calm areas
- **Neutral 900 (#1A1815)**: Text, borders (bold style)

## Component Patterns
- Cards: White bg + bold border + soft shadow + hover lift
- Buttons: Bold + rounded full + shadow (brutal style)
- Inputs: Rounded + bold focus ring
- Progress: Rounded full + gradient fill
- Badges: Rounded full + bold colors
- Icons: From react-icons + playful positioning

## Animation Strategy
- Entrance: Fade in + slide up
- Hover: Lift + shadow increase
- Click: Push down effect (brutal shadow)
- Success: Confetti + bounce
- Loading: Pulse + float
- Decorative: Float + rotate
